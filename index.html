1. 适用范围

health&wealth 供开发者本人及经开发者允许的用户使用。每位用户必须使用自己的 WHOOP 账户完成 OAuth 授权。开发者的使用许可不代替用户对数据访问的授权。

Who can use this app

health&wealth is intended for the developer and users permitted by the developer. Each user must authorize access through OAuth using their own WHOOP account. Permission to use the app does not replace the user’s consent to data access.

2. 数据与用途

应用仅按用户授予的权限读取 WHOOP 恢复、睡眠、每日身体负荷和运动数据，包括相关心率指标。数据用于个人趋势分析和饮食、运动、睡眠安排参考，不用于医疗诊断或治疗。

Data and purposes

The app reads WHOOP recovery, sleep, daily strain and workout data, including related heart-rate metrics, within the permissions granted by each user. Data is used for personal trend analysis and suggestions about meals, exercise and sleep, not medical diagnosis or treatment.

3. 数据流向与接收方

本说明对应 ChatGPT 自定义 GPT Actions 直接访问 WHOOP 官方接口的方案。查询返回的数据会发送给 OpenAI，在用户的 ChatGPT 对话中处理。WHOOP 和 OpenAI 按各自政策与用户账户设置处理数据。

Data flow and recipients

This notice covers a design in which ChatGPT custom GPT Actions access the official WHOOP API directly. Retrieved data is sent to OpenAI for processing in the user’s ChatGPT conversation. WHOOP and OpenAI handle data under their respective policies and the user’s account settings.

4. 保存与安全

本方案不另设开发者托管的健康数据数据库。第三方平台可能保留对话、授权凭证或服务日志，保留期限取决于其政策与账户设置，不承诺零留存。用户不应在对话或公开仓库中提供密码、Client Secret 或访问令牌。

Retention and security

This design does not include a developer-hosted health-data database. Third-party platforms may retain conversations, authorization credentials or service logs under their policies and account settings; zero retention is not promised. Users should not put passwords, client secrets or access tokens in conversations or public repositories.

5. 共享与用户隔离

本项目不出售健康数据，也不将其用于广告。使用某位用户的数据须经该用户授权；不得通过共享开发者的 WHOOP 令牌向其他用户开放开发者数据。用户不应分享含健康数据的对话链接。公开本政策不会公开健康数据。

Sharing and separate user access

This project does not sell health data or use it for advertising. Access to a user’s data requires that user’s authorization; the developer’s WHOOP token must not be shared to expose the developer’s data to others. Users should not share conversation links containing health data. Publishing this notice does not publish health data.

6. 撤销授权与删除

用户可通过 WHOOP 提供的连接管理或撤销授权方式停止后续访问，并在 ChatGPT 中断开连接、管理或删除相关对话。撤销授权不会自动删除此前传给第三方服务的数据，删除请求需向相应服务提出。

Revocation and deletion

Users can stop future access using WHOOP’s available connection-management or authorization-revocation mechanisms, and disconnect or manage and delete relevant conversations in ChatGPT. Revocation does not automatically delete data previously sent to third-party services; deletion requests must be addressed to the relevant service.

7. 政策网页

政策网页不展示健康数据或密钥，不包含表单或自行添加的分析追踪脚本。部署至 GitHub Pages 后，GitHub 可能按其隐私政策处理提供网站服务所需的访问日志。

This policy website

This policy page displays no health data or secrets and includes no forms or custom analytics scripts. Once hosted on GitHub Pages, GitHub may process access logs needed to provide the website under its privacy policy.

8. 联系与更新

联系邮箱：待开发者补充。开放给其他用户前须填写有效联系渠道，并确认实际数据处理与本说明一致。若增加存储服务、接收方或改变用途，将更新本说明，并在需要时重新取得授权。

Contact and changes

Contact email: to be provided by the developer. A valid contact channel must be added and actual data handling verified against this notice before access is offered to other users. This notice will be updated if storage, recipients or purposes change, with renewed authorization where needed.
